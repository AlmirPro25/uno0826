## 📋 Checklist Antes de Mostrar

### Para Investidores
- [ ] Pitch deck de 10-12 slides
- [ ] Demo funcional (vídeo de 3 min)
- [ ] Métricas (mesmo que projetadas)
- [ ] Tamanho de mercado (TAM/SAM/SOM)
- [ ] Modelo de negócio claro
- [ ] Time (LinkedIn atualizado)
- [ ] Roadmap de 18 meses

### Para Clientes
- [ ] Demo ao vivo funcionando
- [ ] Caso de uso específico para eles
- [ ] Proposta de piloto gratuito
- [ ] ROI estimado (economia de tempo/dinheiro)
- [ ] Suporte durante piloto

### Para Parceiros
- [ ] Proposta de valor mútuo
- [ ] Modelo de revenue share
- [ ] Integração técnica possível
- [ ] Cases de sucesso (mesmo que poucos)

## 🚀 Plano de Ação Imediato

### Semana 1-2: Preparação
```
□ Gravar vídeo demo de 3 minutos
□ Criar pitch deck
□ Preparar ambiente de demonstração estável
□ Listar 20 clínicas para abordar
□ Criar conta no LinkedIn Sales Navigator
```

### Semana 3-4: Primeiros Contatos
```
□ Aplicar para 3 aceleradoras
□ Contatar 10 clínicas para piloto
□ Agendar 5 reuniões de demonstração
□ Participar de 1 evento de healthtech
```

### Mês 2-3: Validação
```
□ Fechar 2-3 pilotos gratuitos
□ Coletar feedback e iterar
□ Documentar métricas de uso
□ Preparar para captação seed
```

## 💡 Dica Final

**Comece pelos clientes, não pelos investidores.**

Investidores querem ver tração. Se você conseguir 3-5 clínicas usando (mesmo grátis), seu valuation sobe e a conversa com investidores fica muito mais fácil.

```
ORDEM IDEAL:
1. Clínicas piloto (validação)
2. Aceleradoras (mentoria + pequeno capital)
3. Angels (R$ 200-500K)
4. VCs Seed (R$ 1-3M)
```
