# ⚡ COMO ATIVAR O EXECUTOR AGORA

## 🎯 MÉTODO MAIS RÁPIDO (3 CLIQUES)

### 1️⃣ Duplo clique neste arquivo:
```
INICIAR_EXECUTOR_COMPLETO.bat
```

### 2️⃣ Aguarde ~10 segundos
Você verá 2 janelas se abrirem:
- 🟦 Janela azul = Backend
- 🟩 Janela verde = Executor

### 3️⃣ Pronto! ✅
Quando ver estas mensagens, está funcionando:

**Janela Backend:**
```
✅ Conectado ao Maestro!
```

**Janela Executor:**
```
✅ Conectado ao Maestro!
```

## 🐛 SE DER ERRO

### Erro: "Node.js não encontrado"
**Solução:** Instale Node.js de https://nodejs.org/

### Erro: "Python não encontrado"
**Solução:** Instale Python de https://www.python.org/

### Erro: "Executor não está conectado"
**Solução:** 
1. Feche todas as janelas
2. Execute novamente: `INICIAR_EXECUTOR_COMPLETO.bat`

### Erro: "Port already in use"
**Solução:**
1. Feche todas as janelas
2. Aguarde 5 segundos
3. Execute novamente
