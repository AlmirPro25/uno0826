## 🔬 Cenário 5: Pesquisador Analisando Dados

### Situação
Trabalhando com Python e Pandas para análise de dados.

### Como o Sistema Ajuda

**1. Detecção de Contexto**
```
[Sistema vê Jupyter Notebook com Pandas]
IA: "Vejo que está fazendo análise de dados. Posso ajudar 
com visualizações ou estatísticas?"
```

**2. Sugestões de Otimização**
```
⚡ Otimização:
"Seu loop está processando 1M de linhas. Considere usar 
df.apply() ou vectorização para 10x mais velocidade:

df['result'] = df['column'].apply(lambda x: x * 2)
# vs
for i in range(len(df)): ...  # Lento
```

**3. Análise Estatística**
```
Você: "Esses dados parecem normais?"

IA: "Vou analisar a distribuição... [analisa gráfico na tela]
- Média: 45.2
- Desvio padrão: 12.8
- Skewness: 0.3 (levemente assimétrico)
- Conclusão: Aproximadamente normal, mas com leve cauda à direita"
```

**4. Memória de Métodos**
```
[Sistema lembra]
- Métodos usados: Regressão linear, ANOVA
- Bibliotecas: Pandas, Matplotlib, Scipy
- Tipo de dados: Séries temporais

IA: "Como você trabalha com séries temporais, sugiro 
adicionar análise de autocorrelação com statsmodels."
```

## 💡 Dicas para Maximizar Inteligência

### 1. Seja Específico
❌ "Ajuda com código"
✅ "Como otimizar este loop Python que processa 1M de registros?"

### 2. Use Contexto Visual
❌ Descrever o problema em texto
✅ Mostrar na tela + perguntar

### 3. Dê Feedback
❌ Aceitar resposta sem comentar
✅ "Perfeito!" ou "Prefiro mais detalhes"

### 4. Explore Personalidades
❌ Usar sempre a mesma
✅ Testar diferentes para diferentes tarefas

### 5. Revise Memórias
❌ Nunca olhar o que foi aprendido
✅ Revisar mensalmente e ajustar
