# ⚡ Início Rápido - Executor

## 🎯 3 Passos para Começar

### 1. Instalar Python

```bash
python --version
# Deve ser 3.10 ou superior
```

Se não tiver, baixe: https://www.python.org/downloads/

### 2. Instalar Dependências

```bash
cd executor
pip install -r requirements.txt
```

### 3. Iniciar

```bash
python executor.py
```

**Windows:** Duplo clique em `START_EXECUTOR.bat`

## ✅ Pronto!

## 🎮 Usar

1. Abra a interface web
2. Vá até "Executor Control"
3. Clique em "Conectar"
4. Digite comandos!

## 💡 Exemplos

- "Mover mouse para 500, 300"
- "Clicar"
- "Digitar Olá mundo"
- "Abrir bloco de notas"

## 🛑 Parar

- Pressione `Ctrl+C` no terminal
- OU mova o mouse para o canto superior esquerdo
- OU clique no botão "PARAR" na interface

Simples assim! 🚀
