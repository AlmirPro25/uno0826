## 🎯 O Problema

Ferramentas de IA como ChatGPT, Copilot e Claude são **generalistas**. Quando você pergunta sobre autenticação, pagamentos ou infraestrutura, recebe respostas genéricas que ignoram:

- ❌ Trade-offs reais de cada abordagem
- ❌ Padrões enterprise-ready
- ❌ Contexto específico do domínio
- ❌ Código que funciona em produção
- ❌ Filosofia e "porquê" das decisões

## 🧠 Como Funciona

### 1. Detecção de Contexto
```typescript
// O sistema analisa seu prompt e detecta keywords
"Como fazer autenticação segura com MFA?"
     ↓
Keywords detectadas: ["autenticação", "segura", "MFA"]
     ↓
Manifesto ativado: AUTH_PAYMENTS_FORTRESS
```

### 2. Injeção de Conhecimento
```typescript
// O manifesto é injetado no contexto da IA
{
  philosophy: "Paranoia não é bug, é feature",
  patterns: ["bcrypt cost 12+", "timing attack prevention", "rate limiting 3 camadas"],
  code: "// Implementação enterprise-ready...",
  tradeoffs: {
    "Passkeys": { wins: ["phishing-resistant"], loses: ["browser support"] },
    "TOTP": { wins: ["universal"], loses: ["phishing vulnerable"] }
  }
}
```

### 3. Pipeline de 3 Fases
```
FASE 1: PLANEJAMENTO
├── Análise do prompt
├── Seleção de manifestos
└── Criação do plano

FASE 2: EXECUÇÃO
├── Geração de código
├── Aplicação de padrões
└── Integração de conhecimento

FASE 3: VERIFICAÇÃO
├── Validação de código
├── Testes automáticos
└── Score de qualidade
```

## 🚀 Instalação

```bash
# Clone o repositório
git clone https://github.com/AlmirPro25/plus.git
cd plus

# Instale as dependências do frontend
npm install

# Instale as dependências do backend
```
