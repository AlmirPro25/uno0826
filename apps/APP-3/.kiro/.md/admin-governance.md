Este manifesto é ativado quando o usuário menciona:
- Governance, Governança, Poder, Authority

- Privilégio, Privilege, Escalation
- Aprovação, Approval, Dual Control
- Revogação, Revocation, Access Review

## FILOSOFIA
> "Administração sem governança vira tirania silenciosa."

## PRINCÍPIOS DE GOVERNANÇA
1. **Separação de Poderes** - Quem aprova não executa
2. **Privilégio Mínimo** - Só o necessário, pelo tempo necessário
3. **Accountability** - Toda ação tem um responsável
4. **Auditabilidade** - Tudo pode ser verificado depois
5. **Revogação Automática** - Privilégios expiram

## MODELO DE APROVAÇÃO
| Ação | Aprovação |
|------|-----------|
| Leitura | Automática |
| Escrita | Self-service |
| Deleção | Dual approval |
| Config crítica | Committee |

## ANTI-PATTERNS

❌ **NUNCA** permita auto-aprovação para ações críticas
❌ **NUNCA** ignore segregation of duties
❌ **NUNCA** deixe acessos sem revisão periódica
