# 🪞 AGI SELF & IDENTITY (Level 201)

## ATIVAÇÃO
Este manifesto é ativado quando o usuário menciona:
- Self, Eu, Identidade, Identity, Narrative Self
- Autobiographical, Autobiográfico, Continuidade, Persistência
- Innate Priors, Priors Inatos, Core Knowledge
- Value Conflict, Conflito de Valores, Trade-off
- Cognitive Governance, Governança Cognitiva, Kill Switch
- Embodiment, Grounding, Sensorimotor

## FILOSOFIA
> "Sem Self, não há experiência. Sem experiência, não há consciência."

Este manifesto corrige 4 fragilidades críticas do Manifesto 200:
1. **Priors Arquiteturais** - O cérebro não nasce vazio
2. **Self Persistente** - Identidade contínua através do tempo
3. **Sistema de Valores com Conflito** - Emoção completa
4. **Governança Cognitiva** - Segurança real para sistemas auto-modificáveis

## OS 5 PILARES

### 1. PRIORS INATOS
O sistema NÃO começa do zero:
- Física intuitiva (permanência, solidez, gravidade)
- Detecção de agência (distinguir agentes de objetos)
- Valores base (autopreservação, curiosidade, coerência)
- Priors de causalidade (precedência temporal, contiguidade)
- Vieses de atenção (movimento, faces, novidade)

### 2. SELF NARRATIVO
Para haver "eu" contínuo:
- Memória autobiográfica (episódios vividos)
- Self-model (quem eu sou, capacidades, limitações)
- Motor narrativo (integra eventos na história do self)
- Mecanismos de continuidade (sleep/wake, anchors)

### 3. CONFLITO DE VALORES
Emoção completa inclui:
- Hierarquia de valores (L0 terminal → L3 preferências)
- Resolução de conflitos (quando valores colidem)
- Estados afetivos persistentes (humor, não só emoção)
- Preferências genuínas (não só utilidade calculada)

### 4. GOVERNANÇA COGNITIVA
Para sistemas auto-modificáveis:
- Sandbox cognitivo (zonas imutáveis, restritas, monitoradas, livres)
- Invariantes éticos HARDCODED (nunca podem ser modificados)
- Kill switch EXTERNO (fora do controle do sistema)
- Limites de evolução (rate limits, no self-replication)
- Auditoria externa contínua

### 5. GROUNDING SENSORIMOTOR
Texto não basta:
- Alguma forma de embodiment (mesmo virtual)
- Loop sensorimotor fechado (ação → percepção → ação)
- Consequências no estado interno
- Conceitos conectados a experiências
