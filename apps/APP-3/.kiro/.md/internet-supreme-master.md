## MODELO OSI vs TCP/IP

### Modelo OSI (7 Camadas)
```
7. Aplicação    → HTTP, FTP, SMTP, DNS
6. Apresentação → SSL/TLS, Compressão
5. Sessão       → Estabelecimento de conexão
4. Transporte   → TCP, UDP
3. Rede         → IP, ICMP, Roteamento
2. Enlace       → Ethernet, Wi-Fi, MAC
1. Física       → Cabos, Fibra, Rádio
```

### Modelo TCP/IP (4 Camadas)
```
4. Aplicação  → HTTP, DNS, SMTP
3. Transporte → TCP, UDP
2. Internet   → IP
1. Acesso     → Ethernet, Wi-Fi
```

> "Cada camada ignora a complexidade da camada abaixo."

## PROTOCOLOS FUNDAMENTAIS

### IP (Internet Protocol)
- Endereçamento (IPv4: 32 bits, IPv6: 128 bits)
- Roteamento (best-effort, sem garantia)
- Fragmentação de pacotes

### TCP (Transmission Control Protocol)
- Confiabilidade (acknowledgments)
- Ordem (sequence numbers)
- Controle de congestionamento
- Three-way handshake (SYN, SYN-ACK, ACK)

### UDP (User Datagram Protocol)
- Sem conexão
- Sem garantia de entrega
- Baixa latência
- Uso: Jogos, streaming, VoIP, DNS

### DNS (Domain Name System)
- Traduz nomes em IPs
- Hierárquico e distribuído
- Root servers → TLD → Authoritative
- Cache em múltiplos níveis

### HTTP/HTTPS
- Request-Response
- Stateless
- Métodos: GET, POST, PUT, DELETE, PATCH
- HTTP/2: Multiplexing, Server Push
- HTTP/3: QUIC (UDP-based)

### BGP (Border Gateway Protocol)
- Roteamento entre sistemas autônomos
- "O protocolo que mantém a Internet unida"
- Vulnerável a hijacking
