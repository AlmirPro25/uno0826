  OS 6 EIXOS FUNDAMENTAIS:
  
  📐 EIXO 1 - MODELO FORMAL DE COMPUTAÇÃO:
     • von_neumann - Memória unificada, fetch-decode-execute
     • harvard - Memória separada (instruções/dados)
     • dataflow - Execução dirigida por dados
     • actor_model - Entidades com mailbox, sem estado compartilhado
     • message_passing - Comunicação por mensagens (CSP, π-calculus)
     • event_driven - Loop de eventos, callbacks
     • capability_based - Acesso por capabilities, não por identidade
  
  📜 EIXO 2 - TOKEN ISA (Instruction Set Architecture Abstrata):
     • T_PROCESS_CREATE, T_PROCESS_EXIT, T_PROCESS_YIELD
     • T_MEMORY_MAP, T_MEMORY_UNMAP, T_MEMORY_PROTECT
     • T_IPC_SEND, T_IPC_RECEIVE, T_IPC_CALL
     • T_SCHEDULE_SET_PRIORITY, T_SCHEDULE_SET_AFFINITY
     • T_INTERRUPT_REGISTER, T_INTERRUPT_ENABLE, T_INTERRUPT_DISABLE
     • T_TIME_NOW, T_TIME_SLEEP, T_TIME_SET_TIMER
     • T_CAPABILITY_GRANT, T_CAPABILITY_REVOKE
  
  🔄 EIXO 3 - INTENT → TOKEN → IR → BACKEND:
     • ISOLAMENTO_FORTE → capability_based + microkernel
     • PERFORMANCE_MAXIMA → von_neumann + monolithic
     • TEMPO_REAL_HARD → event_driven + EDF scheduler
     • SEGURANCA_MAXIMA → capability_based + formal verification
     • TOLERANCIA_FALHAS → actor_model + supervisor tree
  
  ⏱️ EIXO 4 - TEMPO, CONCORRÊNCIA E FALHA:
     • Scheduling: FIFO, Round Robin, Priority, EDF, CFS
     • Concorrência: threads, processes, actors, coroutines
     • Falha: isolation, recovery, supervision
  
  🔌 EIXO 5 - HARDWARE COMO ENTIDADE VIVA:
     • Boot sequence (BIOS/UEFI → Stage1 → Stage2 → Kernel)
     • Memory hierarchy (registers → L1 → L2 → L3 → RAM)
     • Interrupt model (PIC, APIC, GIC, PLIC)
     • I/O model (port I/O, MMIO, DMA, IOMMU)
  
  🧩 EIXO 6 - EVOLUÇÃO DO SISTEMA:
     • Modularity: monolithic, modular, microkernel, exokernel
     • Versioning: kernel, syscall, ABI stability
     • Hot swap: drivers, services, protocols, policies
     • Policy/Mechanism separation
  
  SYSTEM INTENTS SUPORTADOS:
     • ISOLAMENTO_FORTE - Máxima separação entre componentes
     • PERFORMANCE_MAXIMA - Latência mínima, throughput máximo
     • TEMPO_REAL_HARD - Garantias temporais absolutas
     • TEMPO_REAL_SOFT - Garantias temporais probabilísticas
     • SEGURANCA_MAXIMA - Resistência a ataques
     • MINIMALISMO - Menor TCB possível
     • EXTENSIBILIDADE - Fácil adicionar funcionalidades
     • PORTABILIDADE - Rodar em múltiplas arquiteturas
     • ENERGIA_MINIMA - Baixo consumo
     • TOLERANCIA_FALHAS - Continuar operando com falhas
