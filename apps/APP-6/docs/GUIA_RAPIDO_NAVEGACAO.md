# 🚀 Guia Rápido - Navegação Inteligente

## Como Usar

### 1. Ativar Modo Navegação 🌐

Clique no botão **🌐 Navegação** na barra de ferramentas do chat.

Você verá:
- ✅ Indicador verde "Modo Navegação Ativo"
- ✅ Canvas lateral abre automaticamente
- ✅ Mensagem: "Canvas aberto | Digite URL ou pesquisa"

### 2. Navegar para um Site

Digite qualquer URL:
```
https://mercadolivre.com.br
```

ou

```
Navegue para amazon.com.br
```

**O que acontece:**
1. 🌐 Playwright abre o site
2. 📸 Captura screenshot em tempo real
3. 🧠 Gemini analisa o conteúdo
4. 🎨 Mostra no Canvas (lado direito)
5. 💬 Mostra resumo no Chat (lado esquerdo)

### 3. Ver Resultados

#### No Canvas (70% da tela):
- **📸 Screenshot** - Visualização da página
- **📝 Texto** - Conteúdo extraído
- **🔗 Links** - Todos os links da página
- **🖼️ Imagens** - Todas as imagens
- **🛍️ Produtos** - Se houver produtos

#### No Chat (30% da tela):
- **🧠 Resumo Inteligente** - IA resume o conteúdo
- **📌 Pontos Principais** - Destaques
- **🛍️ Produtos** - Cards com imagem + preço
- **🖼️ Imagens** - Grid de fotos
- **🔗 Links** - Preview de links importantes

### 4. Exemplos Práticos

#### Buscar Produtos:
```
Busque notebooks no mercado livre
```

**Resultado:**
- Canvas: Screenshot da busca
- Chat: 
  - Resumo: "Encontrados X notebooks..."
  - Grid de produtos com fotos e preços
  - Links diretos para comprar

#### Pesquisar Informações:
```
Pesquise sobre inteligência artificial na Wikipedia
```

**Resultado:**
- Canvas: Screenshot do artigo
- Chat:
  - Resumo: "IA é um campo da ciência..."
  - Pontos principais
  - Imagens ilustrativas
  - Links relacionados

#### Navegar e Analisar:
```
Acesse https://github.com/trending
```

**Resultado:**
- Canvas: Screenshot do GitHub
- Chat:
  - Resumo: "Repositórios em alta..."
  - Lista de projetos
  - Links para os repos

### 5. Interagir com Resultados

#### Produtos:
- Clique no card para ver detalhes
- Botão "Ver Produto" abre em nova aba
- Preço destacado em verde

#### Imagens:
- Clique para ampliar
- Modal de visualização em tela cheia
- Fechar com X ou clicando fora

#### Links:
- Hover mostra preview
- Clique abre em nova aba
- Ícone de link externo

### 6. Fechar Canvas

Clique no **X** no canto superior direito do Canvas.

Isso também desativa o modo navegação.

## 🎯 Dicas

### Para Melhores Resultados:

1. **Seja específico**
   - ❌ "busque produtos"
   - ✅ "busque notebooks gamer no mercado livre"

2. **Use URLs completas**
   - ❌ "mercado livre"
   - ✅ "https://mercadolivre.com.br"

3. **Combine com IA**
   - "Navegue para X e me diga os principais pontos"
   - "Busque Y e compare os preços"

4. **Explore as tabs**
   - Screenshot: Visualização geral
   - Texto: Conteúdo completo
   - Links: Navegação
   - Imagens: Mídia
   - Produtos: Compras

## ⚡ Atalhos

- **Ctrl + B** - Ativar/desativar modo navegação
- **Esc** - Fechar Canvas
- **Clique na imagem** - Ampliar
- **Hover no card** - Ver mais detalhes

## 🔧 Solução de Problemas

### Canvas não abre?
- Verifique se o modo navegação está ativo (botão verde)
- Tente recarregar a página

### Screenshot não aparece?
- Aguarde alguns segundos (pode demorar 3-8s)
- Alguns sites bloqueiam screenshots

### Produtos não aparecem?
- Nem todas as páginas têm produtos
- A IA detecta automaticamente

### Análise IA não funciona?
- Verifique se a API Key do Gemini está configurada
- Vá em Configurações > API Key
