## 🆘 SUPORTE E TROUBLESHOOTING

### Problemas Comuns:

#### "Erro ao buscar"
- **Causa:** Backend não está rodando
- **Solução:** `cd backend && node server.js`

#### "Timeout"
- **Causa:** Playwright demorou muito
- **Solução:** Aumentar timeout em `browserService.js`

#### "Nenhum resultado"
- **Causa:** Todas as fontes falharam
- **Solução:** Testar cada fonte individualmente

#### "Erro 503 do Gemini"
- **Causa:** Modelo sobrecarregado
- **Solução:** Sistema faz retry automático

### Onde Buscar Ajuda:
1. Consulte a documentação (8 arquivos disponíveis)
2. Verifique os logs do backend
3. Teste endpoints individualmente
4. Verifique configurações da API Key
