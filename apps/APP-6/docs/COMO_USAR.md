# 🎯 Como Usar - Prox AI Studio

Guia completo de uso do Prox AI Studio.

---

## 🚀 Início Rápido

1. **Inicie o sistema** (se ainda não estiver rodando):
   ```bash
   INICIAR.bat
   ```

2. **Abra o navegador** em:
   ```
   http://localhost:3000
   ```

3. **Digite sua pergunta** no chat e pressione Enter!

## 🔍 Busca Visual Inteligente

### Como Ativar

Use palavras-chave de busca:
- "busque"
- "buscar"
- "procure"
- "procurar"
- "pesquise"
- "pesquisar"
- "encontre"
- "encontrar"

### Exemplos

#### 1. Busca de Produtos

```
Busque iPhone 13
```

**O que acontece:**
1. Sistema detecta: busca de produtos
2. Navega em: Mercado Livre, Amazon, Magazine Luiza, etc
3. Captura screenshots das páginas
4. Analisa visualmente os produtos
5. Retorna:
   - Comparação de preços
   - Melhores ofertas
   - Links diretos
   - Screenshots clicáveis

**Resposta esperada:**
```markdown
Olha, encontrei várias opções de iPhone 13 pra você!

O melhor preço que vi foi R$ 2.899 no Mercado Livre...

🚀 Próximos Passos:
1. [ ] Comparar especificações
2. [ ] Verificar reputação do vendedor
3. [ ] Calcular frete para seu CEP

📸 Screenshots dos Sites:
[Imagens clicáveis]
```

#### 2. Busca de Informações

```
Como abrir uma empresa em Salvador?
```

**Resposta inclui:**
- Informações completas
- Programas governamentais
- Contatos úteis (telefones, endereços)
- Próximos passos acionáveis
- Screenshots dos sites oficiais

#### 3. Busca de Notícias

```
Busque notícias sobre inteligência artificial
```

**Resposta inclui:**
- Resumo das principais notícias
- Links para matérias completas
- Screenshots dos portais
- Fontes verificáveis

## 🎨 Geração de Conteúdo

### Gerar Imagens

```
Gere uma imagem de um gato astronauta no espaço
```

**Modelos disponíveis:**
- Gemini 2.0 Flash (rápido)
- Imagen 4.0 (alta qualidade)

### Gerar Vídeos

```
Gere um vídeo de ondas do mar ao pôr do sol
```

**Configurações:**
- Duração: 5-10 segundos
- Resolução: 720p
- Aspect ratio: 16:9 ou 9:16

### Transcrever Áudio

1. Clique no ícone de microfone
2. Grave seu áudio
3. Sistema transcreve automaticamente

### Personas

Escolha o estilo de resposta:

- **Padrão** - Balanceado
- **Técnico** - Mais detalhado
- **Casual** - Mais informal

## ❓ Perguntas Frequentes

### Como funciona a busca visual?

O sistema:
1. Navega em sites reais
2. Captura screenshots
3. Extrai texto e links
4. Envia tudo para Gemini Vision
5. Gemini analisa texto + imagens
6. Gera resposta natural

### Quanto tempo leva uma busca?

- Busca simples: 5-10 segundos
- Busca visual: 15-30 segundos
- Depende do número de sites

### Posso usar offline?

Não. O sistema precisa de:
- Internet para buscar
- API do Gemini
- Navegação em sites

### Quantos sites são analisados?

- Padrão: 5 sites
- Configurável: 3-10 sites
- Paralelo: todos ao mesmo tempo

### Os screenshots são salvos?

Não. Screenshots são:
- Gerados em tempo real
- Enviados para análise
- Descartados após uso
- Não armazenados

## 🐛 Problemas Comuns

### Busca não funciona

**Solução:**
1. Verifique se backend está rodando
2. Use palavras-chave de busca
3. Seja mais específico

### Resposta muito genérica

**Solução:**
1. Seja mais específico na pergunta
2. Forneça mais contexto
3. Peça detalhes adicionais

### Screenshots não aparecem

**Solução:**
1. Aguarde o carregamento completo
2. Verifique conexão internet
3. Tente novamente
