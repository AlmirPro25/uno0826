# 🎤 Guia Rápido - Sistema de Voz

## Como Gravar Áudio

1. Clique no ícone do **microfone** 🎤 no campo de entrada
2. Permita o acesso ao microfone
3. **Fale normalmente** - o texto aparecerá em tempo real
4. Clique novamente no microfone para **parar**
5. Edite o texto se necessário e envie

## Como Ouvir Mensagens

1. Clique no ícone de **volume** 🔊 em qualquer mensagem da IA
2. A mensagem será lida em voz alta
3. Clique novamente para **parar**

## Como Configurar a Voz

1. Clique no ícone de **configurações** ⚙️ ao lado do microfone
2. Escolha:
   - **Idioma**: Português, Inglês, Espanhol, etc.
   - **Voz**: Recomendamos vozes Google ou Microsoft
   - **Velocidade**: Mais lento (0.5x) até mais rápido (2.0x)
   - **Tom**: Mais grave ou mais agudo
   - **Volume**: 0% a 100%
3. Clique em **"Testar Voz"** para ouvir
4. Clique em **"Salvar"** para aplicar

## Dicas

✅ **Fale claramente** para melhor reconhecimento  
✅ **Use vozes Google/Microsoft** para melhor qualidade  
✅ **Ajuste a velocidade** para sua preferência  
✅ **Funciona offline** com vozes locais  
✅ **100% gratuito** - sem custos de API  

## Atalhos

- 🎤 **Microfone**: Gravar/Parar gravação
- 🔊 **Volume**: Ouvir/Parar leitura
- ⚙️ **Configurações**: Personalizar voz
