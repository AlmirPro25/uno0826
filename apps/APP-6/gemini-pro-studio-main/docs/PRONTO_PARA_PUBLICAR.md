## ⚠️ IMPORTANTE

### Antes de Publicar
- [ ] Feche o WhatsApp bridge se estiver rodando
- [ ] Verifique que não há arquivo `.env` sendo commitado
- [ ] Revise o `git status` para confirmar

### Arquivo .env
O git status mostra que há um arquivo `.env`. **CERTIFIQUE-SE** de que ele está no `.gitignore` e não será commitado!

```bash
# Verificar se .env está ignorado
git check-ignore .env

# Se retornar ".env", está OK!
# Se não retornar nada, adicione ao .gitignore
```
